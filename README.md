# slidesk-extras

Extras for SliDesk

In this repository, you will find plugins, components, templates and themes to use in [SliDesk](https://github.com/gouz/slidesk) (checked with SliDesk 2.25):

- `plugins/`: copy a directory into `plugins/` of your talk; each one has a README
- `components/`: copy the `.mjs` into `components/` of your talk; its usage is in its header comment
- `templates/`: copy a directory into `templates/` of your talk, then use `.[#name]` on a slide
- `themes/`: copy a directory into `themes/` of your talk

This repository is archived, now the hub https://slidesk.link allows users to add their own plugins, components, themes, ...
